# SOLECRAFT — Modern Shoe E-Commerce Website

A responsive, interactive footwear storefront built with semantic HTML5, modern CSS3, and vanilla JavaScript.

## Folder Structure
- `index.html` — Main storefront page with hero banner, product grid, featured drop, and slide-out shopping bag.
- `css/style.css` — Responsive styling, grid layouts, animations, and modal/drawer styles.
- `js/app.js` — Product catalog with online Unsplash shoe imagery, category filtering, size selection modal, and persistent `localStorage` shopping cart.

## How to Run
Open `index.html` directly in any modern web browser.
